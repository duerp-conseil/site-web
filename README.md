# Site duerp-conseil.fr

Site vitrine de DUERP Conseil (Maxime De Witte EI), publié avec GitHub Pages.

## Pages métier et guides

Les pages `/duerp-.../`, `/metiers/`, `/guides/`, `sitemap.xml` et `robots.txt` sont générées.
Modifier les textes dans `generateur/metiers.py` et `generateur/guides.py`, puis lancer :

    python3 generateur/build.py
